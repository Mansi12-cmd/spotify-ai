--------------------------------------------
Part I - Fix your environment variables
--------------------------------------------
1. Rename the file ".env.example" to ".env"



---------------------------------------------------
Part II - Get Groq API key best free unlimited LLM
---------------------------------------------------
2. Go to the website -> https://groq.com/

3. Click on "Start Building"

4. Log in with Google

5. Click on "API Keys"

6. Click on "+ Create API Key"

7. Set Display Name to "Spotify AI" | Keep Expiration as "No Expiration"

8. Copy the API key

9. Paste it in .env file where it says "GROQ_API_KEY"



----------------------------------------------------
Part III - Get Spotify ID and secret key
----------------------------------------------------
10. Make sure you have Spotify Premium Subscription

11. Go to the website -> https://developer.spotify.com/

12. Click on the three horizontal bars in the top right corner -> Log in with Google

13. Once logged in, click on the three horizontal bars again and click on "Dashboard"

14. Click on "Create App"

15. Enter the App name, App description and set Redirect URL as "http://127.0.0.1:8000/callback"

17. Select "Web API" and then check the "I understand ......." box

18. Click on Save and copy your SPOTIFY_CLIENT_ID and SPOTIFY_CLIENT_SECRET. Paste them in your .env file



--------------------------------------------------------
Part IV - Running the app
--------------------------------------------------------
19. Open Docker

20. Open your project directory and double-click "Spotify AI App" with the black-green icon.

21. Wait for the web interface to load (NOTE: First time initialization might take several minutes)

22. Sign in using your First Name

23. Use the app as you like



---------------------------------------------------------
Part V - Closing the app
---------------------------------------------------------
24. Close the web interface window

25. Open your project Directory in VS Code
==========     OR      ===================
25. Open terminal and go to your project directory

26. Type ```docker-compose down```

27. Your app is now closed



============================================
IMPORTANT
============================================

You only need to do Parts I–III ONCE.

After that, whenever you want to use Spotify AI:

1. Open Docker Desktop.
2. Double-click "Spotify AI App".
3. Wait for the browser to open.
4. Enjoy.
